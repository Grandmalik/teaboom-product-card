# Карточка товара Teaboom.ru — «Ананасовый улун»

Тестовое задание: вёрстка верхней части карточки товара интернет-магазина [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

Стек: HTML5, SCSS, чистый JavaScript (ES-модули), сборщик [Vite](https://vite.dev). Без фреймворков и UI-библиотек.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev       # dev-сервер с hot reload: http://localhost:5173
npm run build     # production-сборка в папку dist/
npm run preview   # локальный просмотр собранной версии
```

Сборка в `dist/` использует относительные пути (`base: './'`), поэтому её можно открыть с любого статического хостинга или из подпапки.

Публикация: в `.github/workflows/deploy.yml` лежит workflow для GitHub Pages. После пуша в `master` страница собирается и публикуется автоматически (в настройках репозитория: *Settings → Pages → Source: GitHub Actions*).

## Решения

**Стилистика.** Палитра и шрифты взяты с teaboom.ru: тёмный `#202020`, фирменный жёлтый `#f5d730`, светло-серые плашки `#f6f7f8`, шрифты Open Sans и Oswald. Кнопка «В корзину» повторяет поведение сайта: жёлтая, при наведении цвета инвертируются.

**Шрифты.** Open Sans и Oswald лежат локально в `src/assets/fonts` и подключаются через `@font-face` (`base/_fonts.scss`), без запросов к Google Fonts. Оба шрифта вариативные: один файл на подмножество символов покрывает все начертания. Файлы разбиты по `unicode-range` (кириллица, латиница, latin-ext для знака ₽), и браузер скачивает только нужные. Кириллические файлы предзагружаются через `<link rel="preload">`. В стилях пути к ресурсам идут через алиас `@` → `src` (см. `vite.config.js`), поэтому не зависят от того, в какой папке лежит партиал.

**Отзыв и избранное.** Под названием, как на teaboom.ru, стоят ссылка «Оставить отзыв» (ведёт к отзывам на странице товара на сайте) и кнопка «В избранное». Кнопка избранного — переключатель с `aria-pressed`: в избранном сердце заливается красным. Реального избранного нет, компонент отправляет событие `product:favorite-toggle` с `{ isFavorite }`.

**Увеличение фото.** Клик по фото открывает лайтбокс на нативном `<dialog>`: фокус, закрытие по Esc и возврат фокуса на фото браузер обеспечивает сам. Закрыть можно кнопкой, кликом по подложке или по Esc. Крупное фото загружается лениво, только при открытии. Пока лайтбокс открыт, страница под ним не прокручивается.

**CSS.** Именование по БЭМ, никаких inline-стилей и `id` в стилях. Цвета, скругления и анимации вынесены в CSS-переменные (`base/_tokens.scss`), брейкпоинты — в SCSS-карту с миксинами `media-up` / `media-down`. Mobile-first.

**Адаптивность.** Раскладка карточки собрана на CSS Grid с `grid-template-areas`:

| Ширина | Раскладка |
|---|---|
| < 768 px | одна колонка: заголовок → фото → покупка → описание; в крошках только ссылка «← назад» в родительскую категорию |
| 768–1023 px | фото слева, заголовок и блок покупки справа, описание на всю ширину |
| ≥ 1024 px | фото слева (прилипает при прокрутке), вся информация справа |

Сетка фасовок (2 или 4 колонки) зависит от ширины самого блока покупки, а не экрана, через container queries.

**Фасовки.** Это нативные `radio` внутри `fieldset`, данные лежат в `data-*`-атрибутах. Поэтому:
- работает клавиатура (Tab, стрелки) и скринридеры;
- без JS страница показывает корректную цену фасовки по умолчанию;
- данные легко отдать из шаблона Django без изменения JS.

При смене фасовки обновляются цена, старая цена, артикул, процент скидки на фото и цена за 100 г (для фасовок больше 100 г). Если у фасовки нет скидки (`data-old-price` не задан или не больше цены), старая цена и бейдж скрываются автоматически.

**«В корзину».** Реальная корзина не подключена. По клику кнопка на 2 секунды переходит в состояние «Добавлено», а компонент отправляет событие `product:add-to-cart` с данными фасовки для будущей интеграции:

```js
document.addEventListener('product:add-to-cart', (event) => {
  console.log(event.detail); // { sku: '01306', weight: 100, price: 326.4, oldPrice: 349.2 }
});
```

**Доступность.** Семантическая разметка (`article`, `nav` с `aria-current`, `fieldset/legend`, `dl` для характеристик, `s` для старой цены), видимый фокус (`:focus-visible`), `aria-live` для озвучивания новой цены, скрытые подписи для скринридеров, учёт `prefers-reduced-motion`. Hover-эффекты включаются только на устройствах с курсором (`@media (hover: hover)`).

Проверено на ширинах 375, 768 и 1440 px: горизонтальной прокрутки нет.
